# unraid-hp-ams

HP(E) Agentless Management Service as an Unraid app/Docker container. Tested on a HP MicroServer Gen 8.

## Important Note for Unraid Users
You will need to use a custom kernel such as [this one by thor2002ro](https://github.com/thor2002ro/unraid_kernel) as Unraid does not include the hpilo kernel module by default otherwise you will get an error.
